# Verification: A flat battery

Checked 2026-10-09 by an independent fact-checking agent (facts and options together); corrections applied the same day.

## Corrected
- Phone battery percentage is a charge-based (coulomb-counting) estimate of remaining capacity, not energy: https://developer.android.com/reference/android/os/BatteryManager ; https://www.batteryuniversity.com/article/bu-903-how-to-measure-state-of-charge/
- A battery is "flat" when its voltage falls below a useful level, before all reactants are converted.
- Volta's pile was the first electrochemical battery ("battery" already named banks of Leyden jars): https://www.lindahall.org/about/news/scientist-of-the-day/alessandro-volta
- EMF noted; ions can be molecular.
- Question: the key was the only option in a different form and more technical register; now parallel ("Energy: it has used up the energy stored in its chemicals").
